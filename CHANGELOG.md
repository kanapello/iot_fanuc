# Изменения

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), номера версий —
[SemVer](https://semver.org/lang/ru/). До 1.0.0 совместимость API между минорными версиями не обещается;
формат сообщений коллекторов меняется только новой версией схемы (`telemetry.v2` и т. д.).
Номера в скобках — pull requests в `kanapello/iot_fanuc`.

## [Не выпущено]

### Сбор данных (edge)

- Осторожный опрос первой стойки: проба и коллектор по умолчанию читают минимум, расширенный набор — один раз
  `--recon`; сигналы коллектора задаются в конфиге, период опроса FOCAS 1–5 с (ADR 0007) (#15).

### Таймлайн и аналитика

- Разделение цикла: машинное время, смена заготовки и прерывания каждого цикла; длинная пауза между деталями —
  простой; медианы, гистограммы и сравнение с нормой по программам, сменам и дням; последний цикл на экране
  оператора. Циклы — производная таблица, пересчитываются с таймлайном (ADR 0008) (#16).

### Станки

- QR-паспорт: постоянный код станка, наклейка со ссылкой `/m/<код>` (PDF на станок и лист A4 на участок),
  перевыпуск кода; по наклейке — страница станка для телефона (состояние, таймлайн, заявка), карточка сервиса
  или экран оператора по роли; чужой станок и неверный код — одинаковое «нет доступа». Адрес на наклейке —
  `MM_PUBLIC_URL` (ADR 0009) (#17).
- Вход возвращает только на страницы этого сайта (`next`) (#17).

## [0.4.0] — 2026-11-24

Первая версия с тегом: всё, что сделано с начала проекта.

### Сбор данных (edge)

- Проба FOCAS `edge/tools/focas_probe.py`: модель ЧПУ, серия и версия ПО, число осей (`cnc_sysinfo`), статус с
  расшифровкой, программа, подача, обороты, нагрузка шпинделя, счётчик деталей (#3901 и параметр 6711),
  аварии; время ответа каждого вызова; `--watch`; `--out` — копия вывода в файл UTF-8 (#1, #9).
- Коллектор: драйвер FOCAS, симулятор со сценариями, SQLite-буфер с удалением после PUBACK, постоянный
  `seq`, heartbeat с эпохой буфера, учётная запись брокера на каждый коллектор (#1, #3).
- Fwlib64.dll грузит `fwlibe64.dll` и `fwlib0iD64.dll` по имени: проба и драйвер ставят папку библиотеки
  первой в `PATH` процесса и вызывают `SetDllDirectoryW` на Windows — на живой стойке без этого был
  `EW_NODLL` (#9).

### Приём и хранение

- Контракт `envelope.v1`, `telemetry.v1`, `event.v1`, `heartbeat.v1`; идемпотентный приём по `(msg_id, ts)`,
  PUBACK брокеру только после COMMIT (ADR 0001, 0002) (#1).
- Сырые данные в hypertables TimescaleDB, сжатие телеметрии через 30 дней, отметки пересчёта в БД (#1, #2).
- ACL брокера по площадкам; `ingest` сверяет площадку топика с площадкой коллектора; автосоздание станков —
  только внутри площадки своего коллектора; `autosave_interval 5` у брокера (#3).
- Справочники коллекторов и станков в `ingest` перечитываются раз в 30 с: перенесённый или удалённый
  коллектор перестаёт писать на старое место (#11).

### Таймлайн и OEE

- Состояния RUN / IDLE / STOP / ALARM / SETUP / OFFLINE по правилам, детали со сбросом счётчика, OEE по часам и
  сменам, пересчёт за закрытый период, нормы цикла с `valid_from`, автоматический пересчёт при изменении
  справочников, golden-тесты (#1, #2).

### Организации и доступ

- Организации, площадки, участки; пользователи и роли на узлах иерархии; токены киосков и ТВ; проверка
  доступа в одном месте и тест изоляции по всем маршрутам (ADR 0003, 0004) (#3).
- Пароль, имя, отключение и снятие ролей — только у пользователя, все роли которого в узлах вызывающего (#6).

### Сервис

- Архив геометрической точности (Renishaw QC20, Ballbar 20) только для сервиса: тесты, оригиналы `.b5r` и PDF,
  полярный график, тренд параметра с отметками «столкновение» и ремонтами (ADR 0005) (#4, #5).
- Отметки «столкновение» и записи ремонтов аннулируются с причиной и выпадают из тренда (#7).
- Журнал аварий (коды, длительность, частота, телеметрия за 10 минут до аварии); заявки на ремонт со статусами,
  исполнителем из сервиса, временем реакции и восстановления по таймлайну; журнал ремонтов; обслуживание по
  наработке с напоминаниями (ADR 0006) (#8).
- Шаги заявки хранят указанное время и момент записи; шаг, внесённый задним числом больше чем на 30 минут,
  клиент видит с пометкой (#12).

### Интерфейс

- Цеховой ТВ-дашборд, экран оператора для планшета, аналитика (OEE, таймлайн, Парето), аварии, ремонт и ТО,
  экран сервиса и карточка станка, админка (структура, справочники, пользователи, токены), вход.

### Разработка и эксплуатация

- `make up` поднимает систему на симуляторе с нуля; `make test`, `make lint`, `make recalc`.
- CI на GitHub Actions: backend (ruff, mypy, pytest с testcontainers), edge, сборка фронтенда, Docker-образы (#10).
- Runbooks: быстрый старт, сеть коллектора (#13). Документы приведены к реальному стеку; версия 0.4.0 во всех
  пакетах (#14).

### Не проверено

- Проба и драйвер FOCAS на реальной стойке после исправления загрузки DLL (#9).
