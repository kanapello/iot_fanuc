## Ждёт владельца проекта

- **Первая стойка.** Пройти `docs/runbooks/first-machine.md`: минимум, `--watch` 10–15 минут с `--out`, затем
  один `--recon`, повернуть ручки коррекции, сменить инструмент, повторить `--recon`, сверить с экраном
  стойки. Прислать файл `--out` (и фото экранов). До этого этап 0 — «на стойке не проверено».
- **Защита `main`.** Среда разработки не может менять настройки репозитория. Включить вручную:
  Settings → Branches → правило для `main`: обязательные проверки `backend`, `edge`, `frontend`,
  `image (backend)`, `image (web)`, `image (edge)`; ветка должна быть актуальной; правило — и для
  администраторов; запрет force push и удаления.
- **Тег `v0.4.0` и удаление слитых веток.** Среда не может отправлять теги и удалять ветки на сервере —
  команды в итоговом сообщении задачи о версии 0.4.0 (тег ставится на коммит `b029855`).
- **Решения сервисного модуля** — раздел «Решения, которые стоит подтвердить» в `docs/service-repairs-report.md`;
  разделения цикла — тот же раздел в `docs/cycle-split-report.md`; QR-паспорта — в `docs/qr-passport-report.md`
  (в том числе: оператор по наклейке попадает на экран оператора).
- **Адрес для QR-наклеек.** На сервере за HTTPS задать `MM_PUBLIC_URL` (например, `https://mm.example.com`) до печати
  наклеек: ссылка печатается в QR и меняется только перепечаткой.

## Что сейчас не делаем

| Что | Почему |
|---|---|
| Драйвер сухих контактов | Сначала FOCAS на первой стойке |
| Постоянное чтение нагрузок и коррекций в коллекторе | Только после замеров, как стойка переносит опрос; пока — разовая разведка `--recon` |
| Автоопределение столкновений, «чёрный ящик» PMC | Нужны данные с реальных стоек |
| Облако, уведомления (`notify`) | Не на этом этапе |
| PIN и табельные номера операторов, LDAP / SSO, журнал действий | Отдельным этапом |
| Row-level security, журнал входов сервисных инженеров, согласие клиента на доступ | Достаточно фильтра по области доступа в API |
| TLS на брокере, Prometheus и Grafana, бэкапы, установщик Windows | Этап эксплуатации, перед первым внешним клиентом |
| Генерация TS-клиента из OpenAPI, линтер и тесты фронтенда, e2e, pre-commit | Добавлять — отдельной задачей |
