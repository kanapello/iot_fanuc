# Отчёт: осторожный режим опроса (feat/probe-recon)

Дата: 2026-11-24 · Ветка: `feat/probe-recon` · Решение: ADR 0007

## Итог

Проба и коллектор по умолчанию читают со стойки минимум: статус, программу, счётчик деталей и аварии
(аварии — только пока статус показывает аварию). Расширенный набор проба читает один раз по `--recon`;
коллектор читает подачу, обороты и нагрузку шпинделя только если они явно перечислены в конфиге станка.
Система по отношению к стойке только читает — функций записи в ЧПУ нет, это проверяется тестом.

**На реальной стойке не проверено.** Раскладка структур новых вызовов взята по fwlib32.h (0i-D / 30i) и
проверена только на поддельной библиотеке; `fwlib64.cs` в работе не использовался и в репозиторий не попал.

## Что сделано

| Часть | Содержание |
|---|---|
| Проба, минимум | Обычный режим и `--watch`: `cnc_sysinfo` один раз; `cnc_statinfo`, `cnc_rdprgnum`, `cnc_exeprgname`, счётчик деталей (#3901 и параметр 6711), `cnc_rdalmmsg2` при аварии. Время ответа у каждого вызова. Подача, обороты и нагрузка из минимума убраны |
| Проба, `--recon` | Один проход, с `--watch` несовместим: коррекции `pmc_rdpmcrng` G0012 (подача, инверсная логика: 255 − значение), G0030 (шпиндель), G0014 (ROV1/ROV2 → 100/50/25 %/F0) — сырой байт и процент; инструмент #4120; `cnc_rdtimer` (включение, работа, резание, цикл); `cnc_rdsvmeter` с именами осей `cnc_rdaxisname`; `cnc_rddynamic2` для всех осей одним вызовом; `cnc_actf`, `cnc_acts`, `cnc_rdspmeter`; по запросу `--pmc "X0-X15,Y0-Y15"` (до 128 байт на диапазон) и `--diag N[,N...]` (тип данных и осевой тип определяются по ответу стойки) |
| Независимость сигналов | Каждый сигнал — отдельный раздел: ошибка печатается в его строке, следующий читается; `EW_FUNC`/`EW_NOOPT` — «не поддерживается стойкой». Останавливает только потеря связи |
| Коллектор | `signals` в конфиге станка, по умолчанию `[status, program, part_count, alarms]`; `feed_actual`, `spindle_speed`, `spindle_load` — только явно; `status` обязателен. Драйвер FOCAS не вызывает функции отключённых сигналов, поллер публикует только их поля и читает аварии, только если `alarms` в наборе. Период опроса FOCAS — 1 с по умолчанию, 1–5 с допускается |
| Симулятор стенда | В `config.sim.*.yaml` подача, обороты и нагрузка включены явно — графики демо не пустеют |
| Документы | `docs/runbooks/first-machine.md` — порядок у станка; ADR 0007; `ARCHITECTURE.md` 3.5–3.7; README, быстрый старт, runbook сети, пример конфига |

## Критерии готовности

| Критерий | Тест (на `fake_fwlib`) |
|---|---|
| Минимум не вызывает расширенных функций | `test_minimum_report_of_a_healthy_machine`, `test_watch_repeats_only_the_minimum`: счётчик вызовов поддельной библиотеки — ни одного `cnc_actf`, `cnc_acts`, `cnc_rdspmeter`, `pmc_rdpmcrng`, `cnc_rdtimer`, `cnc_rdsvmeter`, `cnc_rdaxisname`, `cnc_rddynamic2`, `cnc_diagnoss`; `cnc_sysinfo` — один раз за три цикла `--watch`; `cnc_rdalmmsg2` без аварии не вызывается |
| `--recon` выполняется один раз | `test_recon_reads_the_extended_set_once`: каждая функция — ровно столько раз, сколько требует один проход (таймеры — 4 вида, PMC — 3 коррекции и 2 диапазона); `test_recon_runs_once_and_not_with_watch`: `--recon --watch`, `--pmc`/`--diag` без `--recon` и неверные диапазоны — отказ с кодом 2 |
| Ошибка одного сигнала не прерывает остальные | `test_recon_signals_are_independent`: на «аварийной» стойке G0014 — `EW_NUMBER`, таймер резания — `EW_NOOPT`, `cnc_rdsvmeter` — `EW_FUNC`, #4120 пуст — все следующие сигналы прочитаны |
| Разбор инверсной коррекции | `test_overrides_are_decoded`: G0012 0xFF → 0 %, 0x9B → 100 %, 0x91 → 110 %; G0030 — прямое значение; G0014 — 100/50/25 %/F0 |
| Коллектор по умолчанию не читает подачу, обороты и нагрузку | `test_focas_driver_reads_only_the_minimum_by_default` (0 вызовов `cnc_actf`, `cnc_acts`, `cnc_rdspmeter`), `test_focas_driver_reads_feed_speed_and_load_only_when_enabled`, `test_machine_config_defaults_to_the_minimum` (период 500 и 6000 мс отклоняются), `test_only_configured_signals_are_published` (лишних полей нет, сообщение соответствует `telemetry.v1`) |
| Только чтение | `test_probe_and_collector_never_write_to_the_cnc`: в исходниках пробы и коллектора нет `cnc_wr*`, `pmc_wr*`, загрузки и удаления программ |
| Таймлайн и OEE работают на минимуме | Строятся из статуса, программы и счётчика деталей; golden-тесты таймлайна и OEE используют только эти поля; телеметрия без подачи, оборотов и нагрузки проходит контракт |

## Что не проверено и что дальше

- Первый запуск на стойке — по `docs/runbooks/first-machine.md`: минимум, `--watch` 10–15 минут, затем
  `--recon`, сверка с экраном стойки. Если значение не совпадает или похоже на мусор — правится раскладка
  структуры этого вызова.
- Длина буфера `cnc_rddynamic2` для всех осей — из `max_axis` из `cnc_sysinfo` (иначе 32): подтвердится
  первым `--recon`.
- Расширять набор коллектора — только после замеров времени ответа на этой стойке.
