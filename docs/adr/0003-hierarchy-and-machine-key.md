# ADR 0003. Иерархия «организация → площадка → участок → станок» и внутренний ключ станка

- Статус: принято
- Дата: 2026-11-17

## Контекст

Система становится сервисом для многих предприятий-клиентов: одна установка, общая база. До этого
станок идентифицировался текстовым `machines.id`, который совпадал с идентификатором в топике MQTT и
задавался коллектором. В разных организациях станки неизбежно называются одинаково (`m01`, `sim01`),
а площадок с кодом `plant1` будет много.

## Решение

1. Новая таблица `organizations`; `sites.org_id` обязателен. Площадка и станок получают внутренние
   ключи: `sites.id` (integer), `machines.id` (bigint). Видимые коды — `sites.code` (уникален в
   организации) и `machines.code` (уникален в площадке, `UNIQUE (site_id, code)`).
2. Все таблицы, ссылающиеся на станок, — сырые данные, ввод оператора, производные данные, нормы —
   хранят внутренний ключ `machine_id bigint`.
3. Топики MQTT: `mm/v1/{org}/{site}/{machine_code}/...`. Формат меняется прямо в `v1`: развёрнутых
   коллекторов нет.
4. `ingest` переводит код станка во внутренний ключ по площадке **своего коллектора** из справочника, а
   не по топику. Организация и площадка топика должны совпасть с площадкой коллектора, иначе — отказ.
5. Справочники (смены, причины простоя и брака, нормы цикла, правила состояний) принадлежат организации
   (`org_id`) и могут быть уточнены для площадки (`site_id`). Площадка использует свои строки справочника,
   если они есть, иначе строки организации. Норма станка важнее нормы площадки, та — нормы организации.
6. Миграция `0004` переносит существующие данные: текстовые коды становятся `code`, ссылки
   переписываются на новые ключи. Производные таблицы создаются заново пустыми, каждый станок помечается
   на полный пересчёт из сырых данных.

## Последствия

- Изоляция данных строится на внутренних ключах: одинаковые коды в разных организациях не смешиваются.
- Таблица календаря смен по-прежнему не материализуется: смены площадки считаются из шаблонов в её часовом поясе.
- Откат миграции `0004` не поддерживается: только восстановление из резервной копии.
- `machine_id` в API, ссылках экрана оператора и Redis — число; код станка — для людей и для edge.
