# Первая стойка: осторожный опрос

Для наладчика, который подключает к системе станок Fanuc (0i-MD и похожие). Пока не измерено, как стойка
переносит опрос, читаем минимум. Система по отношению к стойке **только читает**: ни проба, ни коллектор
ничего не записывают в ЧПУ.

Перед началом — сеть: [collector-network.md](collector-network.md) (`ping`, `Test-NetConnection` на порт 8193).

## 1. Минимум, один раз

```powershell
python focas_probe.py --ip 192.168.10.57 --lib C:\collector\vendor\Fwlib64.dll --out probe-m07.txt
```

Проба один раз читает `cnc_sysinfo` (модель, серия и версия ПО, оси), затем минимум: статус, номер и имя
программы, счётчик деталей (макро #3901 и параметр 6711), аварии — только если статус показывает аварию.
У каждого вызова — время ответа в квадратных скобках.

Проверить на экране стойки: режим и состояние (MEM/EDIT, STRT/STOP), номер программы, показания счётчика
деталей. Какой из двух счётчиков совпадает с экраном — тот и указать в конфиге коллектора (`part_counter`).

## 2. Минимум в работе: --watch

Во время обычной работы станка, 10–15 минут:

```powershell
python focas_probe.py --ip 192.168.10.57 --lib C:\collector\vendor\Fwlib64.dll --watch --out probe-m07.txt
```

Раз в секунду — тот же минимум. Остановить — Ctrl+C. Смотреть:

- время ответа вызовов: десятки миллисекунд — нормально; сотни и больше или рост со временем — увеличить
  период опроса коллектора до 2–5 с;
- не мешает ли опрос работе станка и другим программам, которые подключены к стойке;
- счётчик деталей растёт на деталь, статус меняется вместе с экраном.

## 3. Разведка: один запуск --recon

Только после шага 2. Один проход, без повторов:

```powershell
python focas_probe.py --ip 192.168.10.57 --lib C:\collector\vendor\Fwlib64.dll --recon --out probe-m07.txt
```

Читается расширенный набор: коррекции из PMC (G0012 — подача, G0030 — шпиндель, G0014 — ускоренный ход;
сырой байт и процент), инструмент (макро #4120), таймеры, нагрузка сервоосей с именами осей,
`cnc_rddynamic2` одним вызовом, подача, обороты, нагрузка шпинделя. Что стойка не поддерживает, отмечено
«не поддерживается стойкой» — остальное читается дальше.

По заданию разработчиков можно добавить диапазоны PMC и номера диагностики:

```powershell
python focas_probe.py --ip 192.168.10.57 --lib C:\collector\vendor\Fwlib64.dll --recon --pmc "X0-X15,Y0-Y15" --diag 300 --out probe-m07.txt
```

## 4. Сверка с экраном стойки

1. Повернуть ручку коррекции подачи (например, на 50 %), ручку коррекции шпинделя (например, на 80 %),
   переключить коррекцию ускоренного хода.
2. Сменить инструмент (T-код в MDI или по программе).
3. Повторить `--recon` один раз с тем же `--out`.
4. Сверить с экраном стойки:

| В выводе пробы | На стойке |
|---|---|
| Коррекция подачи, % (G0012, инверсная логика) | положение ручки FEED OVERRIDE |
| Коррекция шпинделя, % (G0030) | положение ручки SPINDLE OVERRIDE |
| Коррекция ускоренного хода (G0014: 100 / 50 / 25 % / F0) | переключатель RAPID OVERRIDE |
| Инструмент, #4120 | текущий T на экране программы или в макропеременных |
| Таймеры: включение, работа, резание, цикл | экран SETTING (таймеры) |
| Нагрузка сервоосей и шпинделя | экран монитора нагрузки (SERVO / SPINDLE MONITOR) |
| `cnc_rddynamic2`: программа, кадр, координаты | экран POS (абсолютные, машинные, относительные) |

Если значение не совпадает или выглядит мусором — это главное, что нужно сообщить разработчикам: раскладка
структур проверена только на поддельной библиотеке.

## 5. Что отправить

Файл `probe-m07.txt` целиком (все запуски дописаны в него по порядку) и, если есть, фото экранов стойки
к шагу 4.

## 6. Коллектор

В конфиге коллектора у станка по умолчанию минимум — его достаточно для таймлайна и OEE:

```yaml
  - id: m07
    driver: fanuc_focas
    ip: 192.168.10.57
    poll_interval_ms: 1000                       # 2000–5000, если стойка отвечает медленно
    part_counter: { source: macro, address: 3901 }
    signals: [status, program, part_count, alarms]
```

Подачу, обороты и нагрузку шпинделя (`feed_actual`, `spindle_speed`, `spindle_load`) добавлять в `signals`
только после разведки и замеров времени ответа на этой стойке.
